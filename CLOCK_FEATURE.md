# Digital Clock Feature Branch

## Overview
This branch contains the implementation of a digital clock application that displays current time in different time zones across PC (Electron) and Android platforms.

## Files to be created:
- PC (Electron): React components for clock display
- Android: Kotlin activities for clock display
- Shared: Types, constants, and utilities
